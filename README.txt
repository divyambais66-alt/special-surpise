ANJU BIRTHDAY WEBSITE — QUICK SETUP

1. Open index.html in your browser to preview the site.
2. Add up to 50 photos in photos/ named photo1.jpg, photo2.jpg ... photo50.jpg.
3. Add an MP3 song at music/song.mp3.
4. Add your recorded voice message at voice/message.mp3.
5. Open script.js and change PASSWORD if you want a different code.
6. Change BIRTHDAY in script.js if the date/time needs changing.

GITHUB PAGES
1. Sign in at https://github.com
2. Open your repository named anju-birthday (or create a new public repository with that name).
3. Upload ALL files and folders from this project. Keep index.html at the repository root.
4. Commit the upload.
5. Open Settings > Pages.
6. Under Build and deployment choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait a minute or two, refresh Settings > Pages, and open the published URL shown there.

IMPORTANT
- GitHub Pages is public: anyone who has the URL can access the website.
- The password in JavaScript is only a cute surprise gate, NOT secure protection; visitors can inspect the code.
- Use photos/music you have permission to share. Large media files may make the site slow.
- File names and uppercase/lowercase must match exactly.
